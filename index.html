MODDING GUIDE

Erstelle eine JSON-Datei mit folgendem Format:

{
  "modInfo": { "name": "Mein Mod", "author": "Steve" },
  "customBlocks": [
    {
      "id": 100,
      "name": "Smaragd-Block",
      "miningTime": 15.0,
      "textureUrl": "https://...",
      "color": "#00ff88"
    }
  ],
  "customRecipes": [
    { "resultId": 100, "count": 1, "ingredients": [{ "id": 20, "count": 4 }] }
  ]
}
  • IDs müssen > 50 sein.
  • MiningTime: Höher = langsamerer Abbau.
  • TextureUrl muss ein gültiges PNG sein (CORS beachten).
